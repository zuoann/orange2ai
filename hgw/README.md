# 慧公文智能体 v2026 1.0

> 单文件、零安装的中文公文智能排版与校验工具，严格遵循 **GB/T 9704-2012《党政机关公文格式》**。

「慧公文智能体」是一个纯前端（HTML + JavaScript）的公文写作助手：粘贴一段草稿，即可自动识别红头、文种、标题、主送机关、正文层级、附件与落款，实时渲染标准 A4 版式，并提供格式校验、一键修复与 Word/PDF 导出。整个应用只有一个 `index.html` 文件，双击即可在浏览器中运行。

🌐 **网页版（在线使用）**：无需下载，直接访问 https://www.205099.xyz/hgw/ 即可使用全部功能。

## 🧰 进阶排版与导出（卡片 06 · F1–F14）

在左侧「**进阶排版与导出**」卡片中集中提供以下 14 项增强能力，开关 / 按钮即时生效，且与既有「HTML 预览 / Word 导出 / PDF 打印」三路同源渲染保持一致：

| 标准内嵌帮助 | **F14** | 内置 14 条 GB/T 9704-2012 标准条目「为什么这样排」，随时查阅。 |
| AI 辅助起草（可选） | **F17** | 可选模块：工具栏「🤖 AI 起草」调用 **OpenAI 兼容接口**（DeepSeek / 通义 / 智谱 / OpenAI 等）按 GB/T 9704-2012 公文规范起草正文。接口配置（地址 / 密钥 / 模型）仅存本机 localStorage；生成结果先预览、可编辑，再「替换正文」或「插入到正文末尾」。默认开启，可在面板内取消勾选隐藏按钮（纯可选，不使用则零网络请求、不影响其他功能）。 |

> **Word 原生大纲级别（便于自动生成二级目录）**：导出的 DOCX 会自动为正文标题设置 Word 原生「大纲级别」——`一、`（一级标题）→ 大纲 1 级、`（一）`（二级标题）→ 大纲 2 级，并依次类推 `1.`→3 级、`（1）`→4 级。该设置**仅写入大纲级别、不改变字体/字号/行距**，正文段落不设大纲级别。在 Word 中打开后，可直接「引用 → 目录 → 自动目录」生成可更新、可跳转、文字可选中的二级（及更深）目录，无需依赖 F8 的估算页码目录。
>
> **F8 与大纲级别联动（域代码目录）**：当勾选「自动生成目录（TOC）」并**导出 Word** 时，工具会在「目录」标题下插入一个 `w:fldSimple` 的 `{TOC}` 域（指令 `TOC \o "1-3" \h \z \u`，即取大纲 1–3 级、生成超链接、隐藏制表符前导符），正是建立在上述大纲级别之上。打开 .docx 后**选中全文按 F9（或右键「更新域」）** 即可生成带真实页码、可点击跳转、可随时更新的目录，文字完全可选中——这是比 F8 预览静态目录更规范的正式目录方案。附件正文不参与大纲，避免目录串入附件标题。
>
> **更新域后自动分页**：上述 `{TOC}` 域之后会紧跟一个 Word 原生分页符（`<w:br w:type="page"/>`）。因此无论目录长短，**F9 更新域后目录始终独占一页**，其后正文自动从下一页开始，不会与目录挤在同一页。该分页符同样经 DOCX 驱动的精确 PDF 沿途保留，故「导出精确 PDF」中目录亦独占一页；HTML 预览的目录块也被强制置于独立一页，保持三路同源。

> **补充能力 · DOCX 驱动的精确 PDF 导出**：「📄 导出精确PDF」以 docx.js 生成的 DOCX 为唯一版式来源，经 mammoth 转 HTML 后用精确 A4 打印视图「另存为 PDF」。与「⬇ 导出 PDF」（直接打印预览）相比，它的版式完全由 DOCX 精确控制、输出为矢量且文字可选中，彻底避免像素栅格化；适用于对版面还原度要求最高的正式印发场景。

> 上述 14 项与既有 16 文种、智能解析、三档校验、Word/PDF（标准 + 精确）/ZIP 导出、模板库、撤销重做等共同构成完整工具链，全部遵循「三路同源」渲染（HTML 预览 / Word 导出 / PDF 打印一致）。

## 🆕 合规体检 · 多文档工作台 · 审阅批注

在既有「三路同源」渲染与 16 文种、智能校验、模板库、批量导出之上，新增三项协作增强能力，全部沿用同一份 `index.html`，零额外安装。

### 🩺 公文合规体检（一键体检 + 评分）

点击工具栏「🩺 公文合规体检」，对当前公文做一次性合规体检：

- **26 条合规规则，分 6 大类**：文种与格式匹配、要素完整性、发文字号规范、正文结构、日期逻辑、版记与附件。
- **综合评分**：按 `100 − 错误×12 − 警告×5 − 提示×2` 计算合规分，进度条直观呈现；按类别逐条列出命中项与建议。
- **导出报告**：点「⬇ 导出体检报告」生成 Markdown 体检报告（含规则、命中项、所用评分），可下载归档。

> 合规体检与「智能校验」（35 条校验规则、三档模式、可一键修复）互补：校验偏「可自动修复的具体问题」，体检偏「整篇合规度评估与归档留痕」。

### 📑 多文档工作台与防丢

- **多文档并行（工作台）**：顶部「📑 多文档」标签栏可「＋ 新建」多份公文并行编辑，点标签切换、✕ 关闭；每份公文独立保存字段、批注与修订。
- **版本快照**：当前公文可「💾 存版本」（或「🕑 历史 → 💾 保存当前为版本」），生成带时间戳的版本，最多保留 30 个；「🕑 历史」中可一键「恢复此版本」。
- **防丢持久化**：
  - 单文档自动草稿（`mzw_draft`）——关闭 / 刷新后弹窗提示恢复。
  - 多文档工作台（`mzw_workspace_v2`）——改动后 800ms 自动保存，并在 `beforeunload` 与每 12 秒兜底落盘；刷新后工作台与当前标题自动恢复。

### 📋 审阅批注

面向「起草 → 送审 → 留痕」场景：

- **划选批注**：在右侧预览区选中正文文字 → 打开「📋 审阅批注」面板 →「📝 添加批注（选中预览文字）」，填入意见即生成带黄色高亮引用（`mark.hl`）的批注卡片，可「🔍 定位」跳转、「🗑 删除」。
- **修订模式**：面板内「🔄 修订模式」开启后，以开启时刻正文为基线，后续改动在导出 / 存版本时经行级比对生成修订记录。
- **导出审阅版**：点「⬇ 导出审阅版」——导出的 Word 中批注短语以**黄色高亮**（`w:highlight w:val="yellow"`）标注，并在文档末页追加「批注与修订记录」独立章节（逐条 引文 + 意见 + 修订记录），便于送审留痕。

> 批注与修订记录随公文（`serializeDoc`）一并持久化，切换文档 / 恢复版本时不丢失。

## 📖 使用示例

### 示例 1：从草稿一键生成标准「通知」

**① 粘贴草稿**（含 Markdown 也无妨）：

```text
××省人民政府文件
×政发202611号
## **××省人民政府关于加快推进数字政府建设的通知**
各市、县人民政府，省政府各部门：
为深入贯彻落实党中央、国务院关于数字中国建设的决策部署，现将有关事项通知如下。
---
一、总体要求
坚持以人民为中心，统筹推进数字政府建设。
（一）基本原则
坚持党的全面领导，坚持整体协同。
二、主要任务
（一）夯实数字基础底座
加快建设一体化政务云平台。
三、保障措施
各地各部门要强化资金保障，确保任务落到实处。
附件：1.数字政府建设重点任务分工表
2.数字政府建设考核评估办法
××省人民政府
2026年8月4日
```

**② 点击「智能解析」** → 系统自动识别并填好：发文机关标志、发文字号（自动规范为 `×政发〔2026〕11号`）、标题、主送机关、正文（含一、二、三级标题）、附件说明（支持「附件：1.名称」「附件 1 名称」「附件1 名称」等多种写法并自动校正为标准格式）、发文机关、成文日期。

**③ 右侧预览区立即呈现标准 A4 红头通知**；确认无误后点「**导出 Word（.docx）**」。

### 示例 4：制作「函」（信函式格式）

2. 版式自动切换为**信函式**：发文机关标志下加武文线（红色上粗下细双线），发文字号居右顶格。
3. 填入商洽内容，导出后即为符合国标的平行文函件。

### 示例 5：粘贴带 Markdown 的草稿，一键净化

草稿中混有 `#`、`**`、`---`、`>`、`-` 等标记时，勾选「**净化符号**」再点「智能解析」，系统会：

- 将 `政发202611号`、`政发（2026）11号`、`政发<2026>11号` 统一规范为 `政发〔2026〕11号`；
- 统计并提示净化处数。

### 示例 7：导入已有文件继续编辑

- 支持 `.txt` / `.doc` / `.docx` / `.wps` / `.md` / `.markdown` 上传：拖拽或点击「**⇪ 上传文件**」即可读取。
  - **`.docx` / `.doc` / `.wps`（统一按 .docx 标准解析）**：借助 mammoth 提取正文、表格，并**自动识别保留原文档内嵌图片**（转为 data URI，智能解析后作为图片块显示、可随 Word/PDF 导出）。其中实为 OOXML 的 `.wps` 与 `.docx` 完全同标准；旧版二进制 `.doc` / `.wps` 无法经 mammoth 识别时，自动退化为纯前端尽力恢复正文文本，再经自动净化后照常智能解析排版。
  - **导入自动净化（`.doc` / `.wps` 二进制兜底时）**：上传后自动执行 `sanitizeImportedText()`，清除二进制文件抽取后常见的**乱码**（BOM、零宽字符、替换符 `�`、C0/C1 控制符、UTF-8 被误读为 Latin-1 的乱码如 `â€"` `Â°` 等）与**空白回行**（多余空行、纯装饰/标点空行），同时压缩中文间多余空格；图片标记 `![图N](data:...)` 与表格结构完整保留。净化数量在导入提示中回报（如「已自动净化：清除乱码 N 处、折叠空白回行 M 处」），随后照常「智能解析」即按 GB/T 9704-2012 规范排版。

### 示例 8：正文标题层级自动编排

粘贴仅用「1. 2.」编号的草稿，系统按首次出现顺序自动编排为规范结构层次；序号错乱（如「二、」后直接「四、」）会自动补正：

```text
1.总体要求
坚持党的全面领导。
2.主要任务
（1）夯实基础
（2）强化应用
3.保障措施
```

点击「智能解析」后，正文自动编排为：

```text
一、总体要求
坚持党的全面领导。
二、主要任务
（一）夯实基础
（二）强化应用
三、保障措施
```

> 若文档同时含「1.」与「（1）」但无「一、」，则「1.」识别为三级、「（1）」为四级，四级按（1）（2）… 编号并随三级作用域重置。

### 示例 9：标题冒号智能处理

- **二级标题「标题：正文」同行且无三级标题** → 自动拆分：

  ```text
  一、总体要求：坚持以人民为中心的发展思想。
  ```

  变为：

  ```text
  一、总体要求
  坚持以人民为中心的发展思想。
  ```

- **三级标题末位冒号** → 自动识别为句号：

  ```text
  1.工作要求：强化责任落实。
  ```

  变为：

  ```text
  1.工作要求。强化责任落实。
  ```

- 若二级标题下方存在三级标题，则**不拆分**，保留原样（避免破坏既有结构）。

### 示例 10：宽表格自动横排（横向页）

当正文或附件中的表格总宽超出纵向版心（A4 纵向约 8844 twips）时，系统自动将该表格另页横向排版，符合 GB/T 9704-2012 横向页规则（表格顶边朝左订口、页码置于表格左侧）。在「设置」中可关闭「宽表格/超宽内容自动横排」开关。

也可在表格前插入独立一行强制横排（不渲染该标记行）：

```text
横排
| 列1 | 列2 | 列3 | ……（列数/内容很宽） |
```

### 示例 11：合并单元格表格（rowspan/colspan）完整保留

从 Word / 网页复制或上传 `.docx` 时，若原文档表格存在纵向合并（`rowspan`）或横向合并（`colspan`），系统将以 `<!--TABLE:{...}-->` 结构化注释写入草稿区，**完整保留合并关系**，预览与导出 Word 时不再错位、割裂。

> 例如原 Word 表格中「维度」「领域」列的纵向跨行合并，导入后仍为合并单元格；表头行自动重复，跨页时 Word 会按 GB/T 9704-2012 要求在续页重复表头。

### 示例 12：标题与正文之间的规范间距

无主送机关的公文（如「通用」格式），标题与正文之间自动空一行；有主送机关时，空行体现在主送机关之后。该间距在预览与导出的 Word 中均一致生效，无需手动调整。

## 🛠 技术说明

## ❓ 常见问题

**Q：打开后版式字体不对？**
A：本机未安装方正公文字体，已回退到系统仿宋/宋体/黑体/楷体。安装对应方正字体即可精确还原。

**Q：导出 Word 时提示失败？**
A：请确认网络可访问 CDN（docx.js）。或将三个依赖库改为本地引入实现完全离线。

**Q：PDF 导出空白 / 弹窗被拦截？**
A：允许浏览器弹出窗口后重试；PDF 通过打印窗口「另存为 PDF」，属浏览器原生能力，无需联网。若需最高版面还原度，请使用「📄 导出精确PDF」——它以 DOCX 为版式来源生成矢量 PDF，而非打印屏幕预览。

**Q：解析后附件/落款识别不全？**
A：保持「附件：」「附件1」「成文日期」等关键词规范；复杂稿件可在要素栏手动微调，所有改动实时反映到预览。

**Q：宽表格导出的 Word 里是横向页吗？**
A：是。横向页通过 docx 多 section（PageOrientation.LANDSCAPE）实现，页码按 GB/T 9704-2012 横排规则放置；预览与打印PDF也同步横向渲染。

**Q：合规体检和「智能校验」有什么区别？**
A：两者互补。「智能校验」（35 条规则、三档模式、多数可一键修复）偏「具体可自动修复的问题」；「🩺 公文合规体检」偏「整篇合规度评估」——26 条规则分 6 大类一次性评分（错误×12 / 警告×5 / 提示×2），并支持导出 Markdown 体检报告归档。

**Q：多文档工作台会丢内容吗？**
A：不会。改动后 800ms 自动存入 `mzw_workspace_v2`，并在关闭页面与每 12 秒兜底落盘；单文档另有 `mzw_draft` 自动草稿，刷新 / 重开后会提示恢复。「💾 存版本」还能生成带时间戳的版本快照（最多 30 个），可一键「恢复此版本」。

**Q：「导出审阅版」导出的 Word 长什么样？**
A：正文中的批注短语会以黄色高亮（`w:highlight w:val="yellow"`）标注，并在文档末页追加「批注与修订记录」独立章节，逐条列出 引文 + 意见 + 修订记录，适合送审留痕。普通「⬇ 导出 Word」不受影响。
