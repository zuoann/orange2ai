安全指南

吃菌季，安全第一。请牢记以下要点。

🚫 常见致命误区

  • 「颜色鲜艳才有毒」——错。致命鹅膏、灰花纹鹅膏等剧毒菌多为白色或灰色。
  • 「银针 / 大蒜 / 大米变黑就是有毒」——错。民间检测方法不可靠。
  • 「虫吃过、动物吃过就安全」——错。昆虫与人体的代谢不同。
  • 「高温久煮一定去毒」——对部分毒素无效（如鹅膏肽类）。

✅ 采食原则

  • 只吃100% 确认的菌种；拿不准的坚决不采、不吃、不卖。
  • 不混合多种野生菌一起烹饪，便于溯源。
  • 见手青、牛肝菌等必须彻底煮熟（高温 + 足够时长），不宜凉拌。
  • 饮酒会增加部分菌类中毒风险，吃菌时尽量不饮酒。
  • 老人、儿童、孕妇及体弱者尽量少吃或不吃野生菌。

🚑 误食中毒怎么办

  1. 立即拨打 120，尽快前往医院，切勿自行服药拖延。
  2. 意识清醒者可在专业人员指导下催吐，昏迷者切勿强行催吐。
  3. 保留剩余的菌子样本或照片，供医生与专家鉴定。
  4. 如有多人同时进食，无论是否出现症状都应就医观察。
  5. 记住进食时间、进食量，便于医生判断病情。
